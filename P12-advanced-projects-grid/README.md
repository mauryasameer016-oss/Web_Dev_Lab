# P12: Portfolio Projects Grid

## Objective
Create a responsive gallery of project cards using advanced CSS Grid features.

## Concepts covered
- repeat() and minmax()
- auto-fit and auto-fill
- grid-template-rows
- gap and alignment

## Step-by-step task
1. Open index.html in your browser.
2. Inspect the .project-grid and .project-card rules in styles.css.
3. Add another article card with a title, description and link.
4. Change the minimum card width and observe the number of columns.
5. Resize the browser to phone and desktop widths.

## Files
- index.html — sample project cards.
- styles.css — responsive grid and card styling.
- README.md — this guide.

## Completion check
Cards form a responsive grid without fixed widths or horizontal overflow.

## What to submit
Submit both files, one desktop screenshot and one mobile screenshot, and explain how minmax() helps the layout.

## Beginner tip
Try repeat(auto-fit, minmax(220px, 1fr)) before changing individual card widths.
