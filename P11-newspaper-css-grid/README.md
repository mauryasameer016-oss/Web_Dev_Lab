# P11: Newspaper-style Three-Column Layout

## Objective
Build an editorial newspaper page using CSS Grid. The lead story, supporting story and sidebar should form three columns on a wide screen and stack on a phone.

## Concepts covered
- display: grid
- grid-template-columns
- gap and grid-column
- responsive media queries

## Step-by-step task
1. Open index.html in your browser.
2. Inspect the three content areas: lead story, secondary story and sidebar.
3. Open styles.css and find .newspaper-grid.
4. Change the column proportions and gap.
5. Resize the browser and adjust the media queries.
6. Add one more short article of your own.

## Files
- index.html — sample newspaper content.
- styles.css — three-column CSS Grid layout and responsive breakpoints.
- README.md — this guide.

## Completion check
The page displays three columns on desktop, then two and one columns on smaller screens. No horizontal scrolling should appear.

## What to submit
Submit both files, a desktop and mobile screenshot, and a short explanation of why Grid suits this layout.

## Beginner tip
Use browser developer tools to test widths. Start with the desktop grid, then simplify it for narrow screens.
