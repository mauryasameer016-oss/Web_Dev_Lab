# P1: Terminal Navigation

## Objective
Create a project folder, move into it, inspect files and create a simple folder structure.

## Concepts covered
Read the starter file, identify the important commands or HTML/CSS properties, and understand what each one changes before editing it.

## Step-by-step task
Run mkdir web-practice, cd web-practice, pwd, mkdir html css images docs, touch html/index.html docs/notes.txt and ls. On PowerShell, create files with New-Item html/index.html -ItemType File.

## Files in this folder
- README.md — this practical guide, task instructions and completion check.
- commands.txt — the beginner-friendly starter file for this practical.

## How to start
1. Open this folder in VS Code.
2. Read the starter file from top to bottom.
3. Follow the task and personalise the example.
4. For HTML tasks, open the page in a browser. For CSS tasks, link the stylesheet to a basic HTML page or create one using the HTML starter from another practical.
5. Save, refresh and test your work.

## Completion check
Confirm that pwd shows web-practice and ls shows html, css, images and docs.

## What to submit
- The completed starter file.
- A browser screenshot for practicals that create a webpage.
- Two or three sentences in your own words describing what you learned.

## Beginner tip
Make the smallest working version first. Then change one thing at a time and refresh the page to see the result.
