# P13: Choosing Flexbox or Grid

## Objective
Compare Flexbox and Grid, then choose the simplest layout system for each part of a shared page.

## Concepts covered
- Flexbox for one-dimensional alignment
- CSS Grid for rows and columns
- Combining layout systems
- Choosing a tool based on content relationships

## Step-by-step task
1. Open index.html in your browser.
2. Inspect the header and navigation. The stylesheet uses Flexbox there.
3. Inspect .layout-grid. The stylesheet uses CSS Grid for the content cards.
4. Temporarily experiment with a Flexbox layout for the cards.
5. Restore Grid and compare alignment and sizing.
6. Add a paragraph explaining why you chose each layout system.

## Files
- index.html — comparison content.
- styles.css — Flexbox navigation and Grid content.
- README.md — this guide.
- reflection-template.md — questions to help you write your own conclusion.

## Quick comparison

| Need | Good starting choice |
| --- | --- |
| A row of navigation links | Flexbox |
| A two-dimensional card gallery | Grid |
| Aligning an icon and label | Flexbox |
| A page with main content and sidebar | Grid |

## Completion check
You can explain that Flexbox is one-dimensional and Grid is two-dimensional, and that both can be combined.

## What to submit
Submit both files and a short paragraph with two examples from the project.

## Beginner tip
These tools are not competitors. Use Grid for the overall page and Flexbox inside components when that makes alignment simpler.
