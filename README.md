## Run locally

No build tools or dependencies are required. Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/mauryasameer016-oss/Web_Dev_Lab.git
cd Web_Dev_Lab
```

You can also use the VS Code Live Server extension for automatic browser refresh.
